# Cashflow Europe Planner

Отдельный мультивалютный cashflow planner для европейского проекта.

- операции и прогноз выручки в USD или EUR;
- плановый курс EUR → USD;
- отдельные текущие остатки USD и EUR;
- все сводные показатели, график и доинвестиции рассчитываются в USD;
- данные хранятся локально в браузере и экспортируются/импортируются через JSON.
